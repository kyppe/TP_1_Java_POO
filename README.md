# TP1 Java POO – Système de gestion d'un zoo

Un dossier par étape (chaque étape reprend la précédente) :

| Dossier | Contenu |
|---|---|
| section2_classe_objet | Classe/objet – solution Exercice 1 |
| section3_encapsulation | Attributs privés, getters/setters – Exercice 2 |
| section4_heritage | Lion, Perroquet, Requin – Exercice 3 |
| section5_polymorphisme | faireDuBruit(), instanceof – Exercice 4 |
| section6_abstraction | Animal abstraite + interface Nourrissable – Exercice 5 |
| section7_composition_final | Projet final avec Enclos – Exercice 6 (Exercice6.java) |

Compiler et exécuter (JDK 17+), depuis un dossier :

    javac -encoding UTF-8 *.java
    java Main
    java Exercice6      # uniquement dans section7_composition_final

Sous Windows, si les accents s'affichent mal : `chcp 65001`.
